**The Copper Ladle: Golden Hour** — a diner-rescue cooking game. Cook Rosa has 12 days to repay a $5,450 loan before the bank takes her diner. Every ingredient cooks in its own real time on six stations (watch the progress rings — no frantic clicking needed), dishes build layer by layer and transform into finished plates, and a full kitchen of systems keeps service lively: a 12-stage star ladder, leveled shop upgrades that shave real seconds off cooking, combo tiers and FEVER mode, dish of the day, order variations, drinks, mise en place, phone takeaway orders, a loyal named regular, decor, story scenes, achievements, endless mode and two difficulties. All art, music and sound are drawn and synthesized in code; the game plays fully offline in a desktop browser.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 in a desktop browser. To hand the entry in:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
